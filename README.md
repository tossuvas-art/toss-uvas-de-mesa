# Toss Uvas de Mesa

Site institucional da Toss Uvas de Mesa.

## Publicação gratuita

O site é estático (HTML, CSS e imagens) e pode ser publicado gratuitamente pelo GitHub Pages.

### Ativar a publicação
1. Abra **Settings → Pages** neste repositório.
2. Em **Build and deployment → Source**, selecione **GitHub Actions**.
3. Aguarde a execução do fluxo **Publish Toss website** na aba **Actions**.
4. Depois que a publicação concluir, a URL do site aparecerá em **Settings → Pages**.

**Importante:** não configure o domínio personalizado nem altere o DNS do Registro.br até revisar e aprovar o site de prévia. Preserve os registros DNS de e-mail existentes.

## Arquivos
- `index.html`: página inicial.
- `.github/workflows/pages.yml`: publicação automática do site.
